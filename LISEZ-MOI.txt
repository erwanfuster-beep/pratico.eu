PRATICO MULTIVERSE — V2
=======================

INSTALLATION SUR GITHUB PAGES
1. Décompresse ce ZIP sur ton ordinateur.
2. Dans ton dépôt GitHub pratico.eu, remplace index.html, style.css, app.js, config.js et ajoute favicon.svg.
3. Clique sur Commit changes. Dans Settings > Pages, vérifie main / (root).
4. Recharge ton site (Ctrl+F5) après le déploiement.
5. Sur téléphone, recharge également la page (au besoin, vide le cache).

SUPABASE
- Ton URL de projet et ta clé publique sont déjà dans config.js.
- Les tables, comptes et fonctions déjà installés restent utilisés.
- Pour ajouter les références Fortnite, CS2, Pokémon, etc., ouvre Supabase > SQL Editor > New query,
  copie le contenu de catalogue_v2.sql, puis clique sur Run.
- Le fichier SQL est pour Supabase UNIQUEMENT : pas besoin de le publier sur GitHub.
- Dans Supabase > Authentication > URL Configuration, configure l'URL du site et les redirections
  autorisées (URL GitHub Pages et domaine personnalisé si utilisé).
- Si les e-mails de confirmation sont activés, confirme l'inscription depuis ton e-mail.
- Ne publie jamais de clé service_role, sb_secret_ ni de mot de passe.

CONTENU
- Accueil gaming avec sept univers et cartes mises en avant.
- Boosters animés : 5 cartes, une pièce par ouverture, délai de 10 min côté serveur.
- Collection filtrable, vente de cartes, marché et achat via fonctions Supabase.
- Comptes et sauvegarde en ligne, interface responsive pour mobile.
- Chance BLACK EDITION 0,001 % PAR CARTE (contrôlée par la fonction SQL existante).

LIMITES
- Les visuels sont des symboles et créations CSS originaux, PAS des images officielles des jeux.
- Les noms de jeux et d'objets sont des références fan non officielles.
- Pas d'achat de boosters avec les pièces dans cette version : les pièces servent au marché.
- Pas de test de bout en bout possible sur ton instance Supabase depuis cet environnement.
- Si ton ancien SQL a été modifié, certains appels RPC peuvent nécessiter une adaptation.
- Projet fan indépendant, sans affiliation aux éditeurs. Aucun argent réel.
